# RaceDay API Endpoint Plan

| HTTP method | Route | Description | Role required | Request body | Expected response |
| :--- | :--- | :--- | :--- | :--- | :--- |
| POST | `/api/auth/register` | Registers a new user as either Organiser or Participant. | None (Public) | `{ "email", "password", "fullName", "role" }` | **201 Created** - Returns user object.<br>**400 Bad Request** - Invalid fields.<br>**409 Conflict** - Email already registered. |
| POST | `/api/auth/login` | Authenticates user and returns JWT token. | None (Public) | `{ "email", "password" }` | **200 OK** - Returns JWT token.<br>**401 Unauthorized** - Invalid credentials. |
| GET | `/api/users/profile` | Retrieves the current user's profile. | Any (Logged-in) | None | **200 OK** - Returns profile.<br>**401 Unauthorized** - No token.<br>**404 Not Found** - Profile missing. |
| PUT | `/api/users/profile` | Updates the current user's profile. | Any (Logged-in) | `{ "fullName", "phone" }` | **200 OK** - Returns updated profile.<br>**400 Bad Request** - Invalid data.<br>**401 Unauthorized** - No token.<br>**404 Not Found** - Profile not found. |
| GET | `/api/events` | Retrieves all events with optional filters. | None (Public) | None | **200 OK** - Returns array of events.<br>**400 Bad Request** - Invalid filters. |
| GET | `/api/events/{id}` | Retrieves a specific event with categories. | None (Public) | None | **200 OK** - Returns event object.<br>**404 Not Found** - Event ID missing. |
| POST | `/api/events` | Creates a new event. | Organiser | `{ "title", "description", "eventDate", "eventTime", "venue", "status" }` | **201 Created** - Returns new event.<br>**400 Bad Request** - Missing fields.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not an Organiser. |
| PUT | `/api/events/{id}` | Updates an existing event. | Organiser | `{ "title", "description", "eventDate", "eventTime", "venue", "status" }` | **200 OK** - Returns updated event.<br>**400 Bad Request** - Invalid data.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not the owner.<br>**404 Not Found** - Event ID missing. |
| DELETE | `/api/events/{id}` | Deletes an event if no active enrolments exist. | Organiser | None | **204 No Content** - Event deleted.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not the owner.<br>**404 Not Found** - Event ID missing.<br>**409 Conflict** - Active enrolments exist. |
| GET | `/api/events/{eventId}/categories` | Retrieves all categories for an event. | None (Public) | None | **200 OK** - Returns array of categories.<br>**404 Not Found** - Event ID missing. |
| POST | `/api/events/{eventId}/categories` | Adds a new category to an event. | Organiser | `{ "name", "distance", "startTime", "entryFee" }` | **201 Created** - Returns new category.<br>**400 Bad Request** - Invalid fields.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not the organiser.<br>**404 Not Found** - Event ID missing. |
| PUT | `/api/categories/{id}` | Updates an existing category. | Organiser | `{ "name", "distance", "startTime", "entryFee" }` | **200 OK** - Returns updated category.<br>**400 Bad Request** - Invalid data.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not the owner.<br>**404 Not Found** - Category ID missing. |
| DELETE | `/api/categories/{id}` | Deletes a category if no active enrolments exist. | Organiser | None | **204 No Content** - Category deleted.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not the organiser.<br>**404 Not Found** - Category ID missing.<br>**409 Conflict** - Active enrolments exist. |
| POST | `/api/enrolments` | Registers participant into a category. | Participant | `{ "categoryId" }` | **201 Created** - Returns enrolment.<br>**400 Bad Request** - Invalid ID.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not a Participant.<br>**404 Not Found** - Category missing.<br>**409 Conflict** - Already enrolled. |
| GET | `/api/enrolments` | Retrieves participant's own enrolments. | Participant | None | **200 OK** - Returns array of enrolments.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not a Participant. |
| DELETE | `/api/enrolments/{id}` | Cancels an active enrolment. | Participant | None | **204 No Content** - Enrolment cancelled.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not your enrolment.<br>**404 Not Found** - Enrolment missing.<br>**409 Conflict** - Event already started. |
| POST | `/api/results` | Captures a participant's finish result. | Organiser | `{ "enrolmentId", "finishTime", "position" }` | **201 Created** - Returns result.<br>**400 Bad Request** - Invalid data.<br>**401 Unauthorized** - No token.<br>**403 Forbidden** - Not an Organiser.<br>**404 Not Found** - Enrolment missing.<br>**409 Conflict** - Result already exists. |
| GET | `/api/events/{id}/results` | Retrieves full leaderboard for an event. | None (Public) | None | **200 OK** - Returns array of results.<br>**404 Not Found** - Event missing. |
